# Inorder Traversal

A Java program to perform inorder traversal of a binary tree.

## Features

- Creates a binary tree
- Traverses the tree from left to right
- Displays the inorder sequence

## Technologies Used

- Java
- Scanner
- Binary Tree

## Concepts Used

- Binary Tree
- Recursion
- Inorder Traversal
- Nodes

## Output

Inorder Traversal: 20 10 40 30 50
